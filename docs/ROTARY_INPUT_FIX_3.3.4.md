# 旋钮丢步与响应修复（2026-09-14，固件 3.3.4）

## 复现

通过实际 `MyControl::loop()` 的主机桩输入 10 格快速位移，3.3.3 仅发出 1 个事件。原代码在每 35 ms 通知一次后把 `oldPosition` 直接更新到最终计数，吞掉了中间完整步进和半格余量。

App 回归测试还复现了两个问题：10 个并发异步输入处理读取相同旧游标，最终只增加 1；旋钮连续转动会重新开始 60 ms 尾部防抖，首个画面要等输入安静后才发送。

## 修复

- 固件使用 64 段固定容量 FIFO。连续同向步进压缩为计数，反转和按钮是顺序边界；每次采样最多入运行时队列 8 步，保持 2 ms 采样调度。半格保留，队列暂满时保留输入并重试，不再每 35 ms 抹平位移。没有输入路径堆分配。
- 运行时先查看 FIFO 头，只有 BLE TX 接受后才移除；输入流为图片 ACK 和控制回执保留四个 TX 槽。旧连接输入不会通知到新连接。
- 事件保留旧 `evt` 字段，增加 `seq`、`pending`。`input_stats` 提供队列深度、峰值、重试、按钮丢弃和排队耗时。App 日志同时记录设备序号和设备/App 待处理条数。
- App 按输入顺序调用当前页面处理器，避免异步游标更新相互覆盖；页面变化、断开连接时丢弃过期的排队输入，异常不会堵住后面的步骤。
- 每步选中色立即更新。旋钮预览不再等待 60 ms 安静期；正在传输的帧完成后只发送最新目标，不排队补播已过时的色号和区域。
- 新能力 `streamRecv:1` 允许取消每张图片前固定 50 ms 等待。缺少能力的旧设备保留原路径；图片 ACK、8112 字节正文、200 ms 本地渐变和已确认的 sRGB 校色保留。

## 验证

- 9 组 C++ 主机测试通过 Clang ASan / UBSan。
- 实际输入控制循环回放 10,000 个样本，包含快转、反转和周期性队列阻塞，22,154 步顺序与参考事件完全一致；另测半格余量、按钮边界、满队列及重连清除。
- App 66 项相关测试通过：队列顺序、错误恢复、页面切换、断开清除、连续输入期间发帧、协议元数据分包、能力兼容，以及既有传图、预览和渐变回归。
- 相关 Dart 静态分析无问题；默认 Wi-Fi/OTA 与 BLE-only 两个固件目标构建成功。
- 3.3.4 已通过 USB 烧录哈希校验；鸿蒙调试 HAP 已覆盖安装并保留用户数据。构建后本地签名配置恢复为原内容。

## 边界

FIFO 有明确上限。持续断链会清除旧输入，OTA 会忽略输入；极端长时间背压下超过 64 次方向/按钮边界仍可能耗尽采样器 FIFO，`backlog_full` 和 `button_drops` 可用于识别这种情况。回放测试验证软件计数和顺序，不代表已经测量实体旋钮触点或鸿蒙端到端光学延迟。`input_stats.max_us` 仅覆盖运行时入队到 TX 入队；图片 ACK 不等于 200 ms 过渡已完成。

## USB 与蓝牙实板记录

- 烧录 0x10000 应用分区通过 esptool 哈希校验；没有擦除 NVS 或更换分区。
- PC / Bleak、480 字节分包、10 张目标图和 10 次后续像素补丁：全部通过 ACK 与最终 DMA 源帧哈希校验；保留 200 ms 本地渐变。
- 本次升级前 ACK 中位数 351.678 ms，升级后 187.538 ms，升级后最大 239.370 ms。两次连接的无线调度有波动，不能将全部差值归因于某一项修改；这些是 PC 传图回执时间，不是实体旋钮到发光的完整延迟。
- 升级后从 PC 开始发图到过渡结束并查到正确 DMA 哈希为 375.86～494.56 ms，包含传输、200 ms 过渡和轮询。
- 另用 20 字节分包、取消头部等待，3 张图及后续补丁均通过校验；本次两组实测均无新增 RX/TX/命令/输入丢弃。
- 实机 F6 能力读取确认 `streamRecv:1`，`input_stats` 可查询且空闲时两个输入队列均为 0。

## 鸿蒙手机联动

手机 PID 32047 在 18:47:46 协商 MTU 512 并完成连接。18:48:25 起实际上传日志确认 `packetSize=480 fadeMs=200 streamRecv=true`。18:48:29.350 收到实体旋钮 `colorPlus seq=3`，18:48:29.355 已开始目标帧传输，App 内调度约 5 ms；图片随后在 379 ms 收到 ACK。手机传输时间与 PC 基准不同，不把 PC 的 188 ms 当作手机端到端指标。旋钮在旧帧传输途中到达时，后续目标等待该完整帧结束以保持协议边界。
